# B-roll inside the animation

Real footage set into the explainer, not only cut away to.

## Pattern

1. Start on a graphic card that states the idea.
2. Open a "window" (masked rect / rounded frame) onto real footage.
3. Let the footage own a beat, then return to graphics to pay off the point.

## Rules

- B-roll must illustrate the line being spoken; no stock filler.
- Keep the caption chip readable over the seam.
- Prefer wide environmental shots over tight faces unless the person asked for close-ups.
- License and attribution belong in the project README when footage is third-party.
