# The edit

What to cut, how to cut it, and how to clean it.

## Deciding the cut

1. Transcribe the take.
2. Mark the single idea the short will teach.
3. Cut everything that does not serve that idea.
4. Prefer one continuous performance over franken-edits when possible.

## Cleaning

- Trim breaths and long pauses that break pace.
- Keep natural pauses that land a point.
- Normalize dialogue; leave headroom for music if you add any later.
- Export a 16 kHz mono WAV for caption timing if your toolkit needs it.

## Output

- `src/edit.json` or equivalent cut list
- `out/voice.wav` (dialogue stem)
- Word-level timings for captions
