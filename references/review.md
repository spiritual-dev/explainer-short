# Review and delivery

One fix round: find everything, fix it together, check once more.

## Pass order

1. Picture: theme tokens, layout, motion settle
2. Captions: freeze, spelling, length
3. Audio: loudness, music under dialogue
4. Cover / end frame
5. ffprobe + mid-frame still

## Ship gate

Use `references/review-rubric.md`. Mean score >= 2.3.

## Delivery set

| File | Role |
|------|------|
| `name.mp4` | Master 1080x1920 |
| `frame-mid.png` | Review still |
| `*-cover.png` | Optional title / end card |
| captions / SRT | If the platform needs them |

Save social drafts as drafts until the person approves publish.
